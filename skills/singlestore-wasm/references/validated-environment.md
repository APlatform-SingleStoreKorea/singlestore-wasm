# 실행 환경과 검증 범위 기록

프로젝트별 실제 실행 환경을 `verification.md`와 도구 보고서에 기록한다. 새 프로젝트는 미실행으로 시작한다. 과거 개발 검증 기록은 이 Skill에 포함하지 않는다.

Rust/Cargo 버전, target, OS/architecture, Python 의존성, Wasm import/export와 메모리 설정을 기록한다. DB 검증을 허용받아 실행한 경우 실제 서버 버전, Wasm 설정, 모듈·메모리·packet 제한과 호출 결과를 별도 기록한다. 컴파일러 성공을 DB 성공으로 대체하지 않는다.

문서의 버전 계열을 정확한 서버 패치 버전과 동일하게 보지 않는다. 다른 함수·ABI·입력/반환 타입·compiler/DB 조합의 관찰 결과는 현재 프로젝트의 검증 증거가 아니다. 메모리 설정과 측정값, 등록과 호출, 분산 실행과 callback 직접 검증도 구분한다. 최종 출력은 [최종 결과 형식](output-format.md)의 실행 환경 제약 표를 따른다.
